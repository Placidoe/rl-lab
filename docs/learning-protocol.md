# RL 学习与实验协议

## 每个实验必须回答

1. 状态、动作、转移、奖励和终止条件分别是什么？
2. 优化目标是什么；它与实际评估指标是否一致？
3. 哪些随机源被固定，评估使用多少 seed？
4. baseline 是什么；变量是否只改变一个？
5. 失败模式是什么，例如 reward hacking、过拟合、分布外动作或 rollout 崩溃？

## 统一记录

每轮至少记录：环境与版本、算法与超参数、模型版本、seed、硬件、环境步数、wall time、
episode return、success rate、variance、eval protocol 与已知局限。

## 安全边界

本仓库的 agent 只在离线或沙盒环境行动。实验奖励、偏好和轨迹均不自动转化为生产规则、
训练标签或真实世界动作授权。
